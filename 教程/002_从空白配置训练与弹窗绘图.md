先做到哪一步，就只执行那一步。本文给出全流程供回看；这次参考代码已准备，新的实验文件夹和虚拟环境由你亲手创建。不要删除旧实验或重装旧环境。

## 这次要完成什么

在旧项目内创建独立的 `carbon-classification` 子目录，用原来400张二分类图像完成可记录、可复查的训练。最大30轮；验证损失连续7轮没有改善时提前停止；始终保存验证损失最小的模型。算法仍为冻结ResNet18特征、训练分类头。轮数更多不保证准确率更高。没有增加随机增强，以便先把运行流程弄懂；后续增强必须评估是否会改变缺陷语义。

学习者运行后才会有新结果。30轮实验尚未执行。

1. 在VS Code按 `Ctrl+K`，松开，再按 `Ctrl+O`，出现“打开文件夹”。

菜单“终端 → 新建终端”，在下面PowerShell的 `PS ...>` 后输入一行命令，再按Enter：

```powershell
& 'D:\VS Code Projects\Tools\Python312\python.exe' -m venv 'D:\VS Code Projects\Python\graduate-vision-learning\carbon-classification\.venv'
```

这条命令调用已安装的Python，执行venv工具，把新环境放进指定目录。成功时可能没有提示；等待 `PS ...>` 再出现，左侧刷新后看到 `.venv`。

检查：


应输出本次 `carbon-classification\.venv\Scripts\python.exe`。不是旧项目、不含face_recognition。这里不用激活环境：每次明确指定解释器即可，也避免PowerShell执行策略问题。

## 4．创建配置和库清单

在左侧右键 `CARBON-CLASSIFICATION` → 新建文件 → 输入 `config.json`。

从 `参考代码/carbon-classification/config.json` 复制完整内容，粘贴到新文件，Ctrl+S。JSON不允许注释和末尾多余逗号，Windows路径的反斜杠要写成两个；参考文件已处理好。

各项作用：binary_data=原始图片位置；max_epochs=最大轮数；batch_size=一次处理图片数；learning_rate=参数更新步长；seed=随机种子；early_stopping_patience=验证损失连续几轮不改善后结束。

再新建 `requirements.txt`，从同名参考文件复制，保存。它只是依赖清单，必须执行安装命令才真正安装。

## 7．正式训练

```powershell

```

按Enter后，读取配置和图片，首次下载官方预训练权重，然后输出Epoch。CPU可能有一段时间没有新文字，不等于卡死。每轮读训练集一次，再检查验证集；模型参数只从训练集学习。

最多30轮，也可能提前停止。代码选出验证损失最小的轮次，加载该模型，最后测试80张图一次。不要根据这80张测试图反复挑参数；已经看过测试结果的这份划分后续属于练习比较，严格研究应另留未接触的数据或设计独立评估。

## 8．保存与弹窗同时进行

默认使用Matplotlib的 `TkAgg` 后端。四张图先保存，然后 `plt.show()` 统一弹出交互窗口。没有调用 `plt.close(fig)` 提前销毁窗口。全部关闭后程序返回PS提示符；等待你关图窗属于正常行为，训练和保存已完成。

有些窗口可能叠在一起，可按Alt+Tab切换。窗口工具栏支持放大、缩小和另存。曲线横轴是轮数；纵轴是损失或准确率。

| 要回答的问题 | 使用哪张图 |
|---|---|
| 是否在学习、是否开始过拟合 | learning_curves.png：训练/验证损失与准确率 |
| 两类之间怎样错分、漏检和误报多少 | confusion_matrix.png：真实类别为行，预测类别为列 |
| 查准率、召回率、F1是否平衡 | per_class_metrics.png：每类指标柱状图 |
| 具体错在哪些图，是否有可观察规律 | test_examples.png：优先展示错误样例 |

错误优先样例不是随机抽样，不要从其中红色标题的比例估计整体准确率。softmax输出的概率也不直接等于可信程度。

若远程运行或不想弹窗：

```powershell
& 'D:\VS Code Projects\Python\graduate-vision-learning\carbon-classification\.venv\Scripts\python.exe' 'D:\VS Code Projects\Python\graduate-vision-learning\carbon-classification\train.py' --no-show-plots
```

若提示Tk相关错误，先检查是否使用本教程解释器，反馈完整报错；不要盲目 `pip install tkinter`。旧主程序用Agg只保存，新参考程序改为默认弹窗；两个文件的行为不同。

## 9．哪些自动生成，哪些你必须创建

你创建：carbon-classification文件夹、train.py、config.json、requirements.txt。

venv命令生成：.venv。pip安装：第三方库。首次运行下载：weights里的预训练模型。

训练生成：runs/resnet18/时间戳目录，包括config_used.json、split.csv、history.csv、best_model.pt、metrics.json、test_predictions.csv和四张图；latest.json记录最近完成的一次实验。时间戳不同，新结果不会覆盖旧结果。

第一次实验代码在“代码归档/首次实验”，算法主体可追溯。归档不是直接运行入口，仍在原项目运行旧版。
